    • Movie-Based Personal Dashboard

    Overview:

    Sometime before I was learning about REST and APIs, I signed up to TMDB and gained access to their API for a movie watchlist project. I ended up using the OMDb API for that instead as it was recommended on Scrimba. Later, I learned how to make a personal dashboard extension and added features like keeping track of a certain cryto coin or real time updates on the weather based on the user's current location. I wanted to create a dashboard using the TMDB API and spent a few days putting it together. As incredible as it is, the extension itself isn't available to the public. I wanted to honor the terms and conditions for using the API for free which understandably forbids commercial use.

    Features:

    • Looks up and displays backdrops at random for existing films.
    • Allows the user to input a title and pulls up films the title applies to at random.
    • Allows users to manually change backdrops and keep them from being switched out on refresh.
    • Blocks backdrops of movies based on selected certifications and genres that may disturb users.
    • Displays the current movie's poster and tagline (unless filtered by the user's preferences)
    • Displays one of up to five goals inputted by the user.
    • Allows the user to change the color and outline of text (with the exception of the settings link and credits bar).
